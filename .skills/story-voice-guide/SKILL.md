# Story Voice Guide

Create a prose voice that fits the story's aesthetic, then keep it consistent as the story develops.

## Workflow

1. Gather the inputs that define the voice: genre, POV, tense, audience, emotional register, influences, and any existing prose or outline.
2. Build a style ledger in [STYLE_LEDGER.md](STYLE_LEDGER.md) with concrete decisions, not vague adjectives.
3. When new plot, character, or tone developments appear, compare them against the ledger and decide what to preserve, refine, or revise.
4. Produce a style guide for a writing agent with the current voice, craft rules, examples, avoid list, and open questions.
5. If the style changes, emit a short delta note explaining what changed and why.

## Decision rules

- Prefer observable guidance over abstract labels.
- Tie choices to the story's actual aesthetic, setting, and character lens.
- If clarity conflicts with atmosphere, favor clarity unless the user says otherwise.
- Keep the voice guide concise enough to apply during drafting.

## Output format

Return:

- Current voice summary
- Core prose rules
- Lexical and syntactic preferences
- Imagery, rhythm, and dialogue notes
- Hard avoids
- State changes since the previous version
- Optional sample paragraph if requested
